Hey, I'm **Wim Wenigerkind**, a 16-year-old developer from Germany.

**My journey started at 9 years old.**

It began simply enough: spinning up a Minecraft server on an old MacBook. But running a full OS just for that felt wasteful, there had to be a leaner way. That led me to Docker, and then further down the stack: I wanted a solution not tied to any single OS, which brought me to hypervisors, and specifically Proxmox VE. From there, the rabbit hole only got deeper.

These days I'm completing an apprenticeship as an application developer, working with Go, PHP, Symfony, Shopware, C#, Odoo, and Java, contributing to open-source projects along the way. I especially enjoy building Docker solutions, CLI tools, and automation scripts that make developers' lives a little easier.
